**GSD — top commands**

```text
/fvgsd:new-project           Initialize a project (greenfield)
/fvgsd:map-codebase          Map an existing codebase (brownfield)
/fvgsd:plan-phase <N>        Create a phase plan
/fvgsd:execute-phase <N>     Execute a phase
/fvgsd:progress              Where am I, what's next
/fvgsd:quick                 Small ad-hoc task with GSD guarantees
/fvgsd:fast "<task>"         Trivial inline task — no subagents
/fvgsd:debug "<symptom>"     Persistent debug session (survives /clear)
/fvgsd:capture               Save an idea / todo / note
/fvgsd:ship <N>              Open a PR from a completed phase
```

More: `/fvgsd:help` (default tour) · `/fvgsd:help --full` (everything) · `/fvgsd:help <topic>` (one section)
