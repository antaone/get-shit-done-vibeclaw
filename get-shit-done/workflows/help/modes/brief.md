**GSD — top commands**

```text
/vgsd:new-project           Initialize a project (greenfield)
/vgsd:map-codebase          Map an existing codebase (brownfield)
/vgsd:plan-phase <N>        Create a phase plan
/vgsd:execute-phase <N>     Execute a phase
/vgsd:progress              Where am I, what's next
/vgsd:quick                 Small ad-hoc task with GSD guarantees
/vgsd:fast "<task>"         Trivial inline task — no subagents
/vgsd:debug "<symptom>"     Persistent debug session (survives /clear)
/vgsd:capture               Save an idea / todo / note
/vgsd:ship <N>              Open a PR from a completed phase
```

More: `/vgsd:help` (default tour) · `/vgsd:help --full` (everything) · `/vgsd:help <topic>` (one section)
